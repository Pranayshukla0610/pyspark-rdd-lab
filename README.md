# PySpark RDD Lab

A practical learning repository for understanding and implementing
**Resilient Distributed Datasets (RDDs)** using Apache Spark and PySpark.

This repository covers the fundamentals of RDDs, transformations,
actions, key-value operations, partitioning, and practical distributed
data-processing examples.

---

## 📌 About

An RDD (Resilient Distributed Dataset) is one of the fundamental
abstractions of Apache Spark.

RDDs provide a distributed, fault-tolerant, and immutable collection
that can be processed in parallel across a Spark cluster.

This repository is designed to provide hands-on experience with RDDs
using Python and PySpark.

---

## 🎯 Objectives

The main objectives of this repository are to:

- Understand the concept of RDDs
- Create RDDs using PySpark
- Perform RDD transformations
- Perform RDD actions
- Work with key-value RDDs
- Understand lazy evaluation
- Explore RDD partitioning
- Implement Word Count using RDDs
- Understand distributed data processing
- Compare RDDs with DataFrames
- Build a foundation for Apache Spark and PySpark
